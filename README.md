# Дмитрий Неронов — Frontend Developer

Портфолио-сайт frontend-разработчика. Сделан без шаблонов и фреймворков.

🌐 **Живой сайт:** [isdmitryy.github.io](https://isdmitryy.github.io)

---

## Стек

- HTML5 — семантическая вёрстка, aria-атрибуты
- CSS3 / SCSS — БЭМ, переменные, миксины, партиалы
- JavaScript — переключатель тем, бургер-меню
- CSS Grid + Flexbox — адаптивная сетка
- GitHub Pages — деплой

---

## Возможности сайта

- Тёмная и светлая тема с сохранением в localStorage
- Адаптивная вёрстка для мобильных, планшетов и десктопа
- Бургер-меню на мобильных устройствах
- SEO-оптимизация и Open Graph теги
- Accessibility: семантический HTML, aria-атрибуты
